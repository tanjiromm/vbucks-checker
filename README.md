# فاحص فيبوكس الزومبي (مجاني بالكامل)

## التشغيل على جهازك
1. ثبّت Node.js (18 أو أحدث).
2. داخل المجلد شغّل: `node server.js`
3. افتح http://localhost:3000

## النشر المجاني على Render
اتبع الخطوات مع Claude. لا تحتاج أي مفتاح أو Environment Variable.

## ملاحظات
- لو موقع تتبّع غيّر شكله، قارئه في server.js (دالة parse) يحتاج تعديل.
- الفحص يحتاج موقعين على الأقل متفقين عشان يعطيك "مؤكد".
